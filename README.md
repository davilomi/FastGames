FastGames Somos un grupo de clase y estamos haciendo una página web de videojuegos. 
Nuestra web La web tiene cuatro páginas: 
- Inicio: juegos destacados. 
- Descuentos: juegos con ofertas. 
- Lo más vendido: lista de los 10 juegos más vendidos. 
- Nuevos lanzamientos: información de próximos juegos. Qué hemos usado 
- HTML para crear las páginas. - CSS para los estilos. 
- Un poco de JavaScript para el carrusel de inicio. 
- Git y GitHub para trabajar en equipo. Archivos 
- index.html - descuentos.html 
- lo-mas-vendido.html - nuevos-lanzamientos.html 
- estilos.css - Carpeta img/ con las imágenes. 
Organización Estamos usando ramas de Git para repartir el trabajo y juntar los cambios mediante pull requests. También organizamos las tareas en un tablero Kanban.
